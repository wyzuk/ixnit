# Vim survival

For when git drops me into vim:

1. Press `Esc`
2. Type `:wq` + Enter (save and quit)
3. Or `:q!` + Enter (quit without saving)

Basic navigation:
- `i` -> insert mode
- `x` -> delete character under cursor
- `dd` -> delete current line
- `u` -> undo
- `/word` -> search for word (n for next)
- `gg` -> go to top
- `G` -> go to bottom
