# Ixnit

A place where I dump things I learn, break, fix, test, and forget.

Mostly short notes, half-finished experiments, commands I keep having to Google, and bugs that took me way too long to figure out.

## Folders

- `notes/` - quick notes on things I'm reading or working with
- `cheats/` - compact cheatsheets for syntax and commands
- `snippets/` - copy-paste code pieces I use often
- `experiments/` - minimal runnable scripts and sandbox tests
- `playground/` - tiny HTML/CSS/JS visual experiments
- `bugs/` - notes on dumb bugs and how I fixed them
- `logs/` - short technical logs from working on different things
- `scripts/` - small bash tools I run locally
- `ideas/` - project ideas and things I want to build later
- `archive/` - old/abandoned stuff I didn't want to delete
