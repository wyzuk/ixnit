# Curated Developer Links & Bookmarks

High quality reference documentation, interactive tools, and learning sites I frequently visit.

## Official Docs & References
* [MDN Web Docs](https://developer.mozilla.org/) - The source of truth for web APIs, CSS, and JS.
* [JavaScript.info](https://javascript.info/) - Outstanding, in-depth deep dives on the JS language.
* [Can I Use](https://caniuse.com/) - Browser compatibility tables for modern frontend features.
* [Node.js Documentation](https://nodejs.org/en/docs/) - Official runtime docs.

## Interactive Tools & Sandboxes
* [Regex101](https://regex101.com/) - Regular expression tester and step-by-step debugger.
* [Bundlephobia](https://bundlephobia.com/) - Find the cost and weight of adding an npm package.
* [Transform.tools](https://transform.tools/) - Polyglot data converter (JSON to TypeScript, SVG to JSX, etc.).
* [DevDocs.io](https://devdocs.io/) - Fast, offline-capable aggregated documentation browser.
