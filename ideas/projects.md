# Weekend project ideas

- [ ] **Tiny CLI note taker**: A single bash script or small node script that appends notes to a markdown file with timestamps.
- [ ] **Tab manager extension**: Minimal chrome extension that dumps all open tabs into a clean markdown list.
- [ ] **Offline audio recorder**: Simple web app using MediaRecorder API to record voice notes and save as .webm.
- [ ] **Regex test visualizer**: Simple page showing matches highlighted in real time without lag.
